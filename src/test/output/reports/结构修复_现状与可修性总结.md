# 结构修复现状与可修性总结

> 修复原则：**通用性优先**。判据必须来自文档自身的独立证据（编号 / Marker 声明的层级 /
> 正文显式引用 / 结构签名），不得来自某篇论文的具体标题或页码；且必须在多篇论文上验证
> 「修对 N 处、误修 0 处」；无法确证时**保守不修**，只出诊断与告警。

## 二、✅ 已修复（判据通用 + 多篇验证）

| # | 问题类 | 判据（通用性来源） | 为什么不是"这篇特有" | 实测证据 |
|---|---|---|---|---|
| 1 | `ReadingOrderRepair` 合并时**误删中间的 Figure/Table** | 只删被合并块 B 与 NoiseBlock，保留其它透明块 | 跨页续接在任何 PDF 都存在；原实现是纯逻辑错误 | 目标论文 tables 3 → **6** |
| 2 | **空锚点 section 被删**（`Methods` 标题丢失） | 标题命中主章节锚点集 **且** 该 section 无 block 无子节点 | Marker 常把"节"与"子节"标成同 depth → 子节被拉平 → 锚点变空。任何论文同形即触发 | sections 35 → 36；告警 `EMPTY_ANCHOR_SECTION_KEPT` |
| 3 | **编号同深度却被父子化**（§5.2） | 标题编号深度（`2.1` vs `2.2`）**完全相等** | 编号是论文自带的层级声明，与标题命名无关；任何带编号论文同形即触发 | LEARNING 7 + JAMC 2 = **9 处，误修 0** |
| 4 | 编号**带尾部句点**（`4.4.6.`）不被识别 | 编号正则支持 `N.N.N.` | 编号是否带句点是排版习惯，跨论文普遍 | 该修正新增 2 处**正确**提级 |
| 5 | **Figure/Table 浮动排版**导致归属错 | **正文显式引用**（类型+编号完全匹配）+ 页距 ≤3 | 浮动排版 + 正文引用是学术 PDF 的普遍特征；**不依赖视觉距离/页码** | 重挂 36 次（有编号浮动块 68），**5 篇全部页距 ≤2**；`Table 3` 归位 |
| 6 | **空孤儿锚点被错嵌在另一锚点下**（`Methods` root，§4 收敛版） | 4 条结构签名：空孤儿 + 父是锚点 + 双方有 `rawLevel` + 有可收编同级（`rawLevel` 相同、遇下一个锚点即停） | "Marker 把某标题的子节拉平成同级"会让锚点变空 → 通用**结构签名**，不依赖具体标题 | `Methods` 提为 root（**1 处**）；其余 4 篇 **0 影响** |
| 7 | `chunkId` 冲突（下游 upsert 主键，会静默丢 chunk） | sectionId 重复时加确定性后缀 + 告警 | 领域模型未保证 id 唯一 → 通用防护 | 单测 + 真实数据 0 冲突 |
| 8 | Figure **只有 label** 也产出垃圾 chunk | 契约：`caption` 与 `descriptionText` 皆空即跳过 | 空 caption 图在任何论文都可能出现 | JAMC 跳 4 / LEARNING 1 / 目标论文 2 |
| 9 | §9 指标**假阳性**（`C.` 被误判罗马数字） | 单字母罗马歧义消解（后续标题全大写才算罗马） | `C.`/`I.`/`V.` 歧义是拉丁字母与罗马数字的固有重叠 | Poly-Window 2 → **0** |
| 10 | 结构问题**不可观测** | 新增 5 个 Validator 指标，且**独立重新计算**（不复用修复组件计数） | 类别级指标，与具体论文无关 | 全程驱动了 #2/#6 的修复与验证 |

## 四、❌ 修不了（本层无可靠证据 / 属上游）

| # | 问题 | 为什么修不了 |
|---|---|---|
| **E** | **无编号**父子是否应同级（`Pre-processing > Baseline models`/`PatchECG`/`SSRL`/`MPM`/`LoRA`；`Scientific contributions > Clinical relevance`） | 编号缺失 + Marker 声明它们**更深** → 本层**没有任何可反驳的证据**。强行修就是"猜"，而 skill §17 把"错误重排"排在"保守不修"之后 |
| **F** | Marker `section_hierarchy` **粒度过粗**（把节与其子节标成同 depth） | 这是 Marker 的输出。已用 47 例证明：`rawLevel` 相同**多数是合法父子** → `rawLevel` 不能当层级证据（只能作审计佐证） |
| **G** | 无编号同级纠偏（§5.3） | 现有诊断出 7 个候选，但**证据不足**（见 E/F）；现状只诊断、不自动修 |
| **H** | Marker **完全没输出**某标题（heading 丢失） | 无标题 = 无信号。除非该处存在其它结构签名（如 #6 的"空孤儿锚点"），否则本层无从发现 |
| **I** | Ghostscript / 字体导致的**字符损坏**（`e→The`、`oen→often`、`Ƥne→fine`） | 属 PDF→文本的上游失真，本层无法可靠还原（不了解字形映射就不该猜） |
| **J** | 浮动块在**正文未引用**时"真正属于哪一节" | 无 ground truth。只能保守不动（现状：9 处 unresolved 一律不动） |
| **K** | 公式/脚注的**语义**（LaTeX/MathML 级） | 本层只做结构保留，不做公式理解（skill 明确不做） |

## 五、🔸 设计取舍（不是缺陷，是 v1 决定）

| # | 现象 | 说明 |
|---|---|---|
| 1 | `undersized` 占 70–82% | 参考文献每条约 45 token（66 条全 undersized）+ 论文含 26 个叶子 section。v1 按决定不跨 Section 合并，只标记；`embeddingText` 前缀提供语义补偿 |
| 2 | `referenceRatio` 0.29–0.52 | 参考文献占向量库 1/3~1/2。v1 只标记不过滤；`chunkType=REFERENCE` 已落到每个 chunk，v2 检索过滤即可 |
| 3 | `overlap` 默认关闭 | 保留实现，便于对比实验 |
| 4 | **Formula / Footnote / 超长段落 / 超长 LIST / 超长 TABLE 切分** | 在 5 篇真实论文中**从未触发**（段落 max 仅 382 token ≪ 1000）→ 仅由合成单测覆盖，属"未经验证的代码"，接入更多论文时需复测 |
| 5 | `ceil(chars/4)` token 估算 | 未与 bge-m3 真实分词器标定；接入 embedding 后应复测并标定 `targetTokens` |

## 六、结论（一句话版）

```text
能通用修的：已完成 10 类（含 9 处编号同级提级、1 处空孤儿锚点重挂、36 处浮动归属、目标论文表格 3→6）
已通用修复   A 罗马前缀（Poly-Window 3 例）· A2 子比父浅（JAMC 2 例）—— 均零副作用
能通用修但没做   3 类：B 标题变体【需设计】/ C 挂载点【需定义】/ D orphan caption【需规则】
修不了的：7 类（无编号同级缺证据 / Marker 层级粒度过粗 / heading 完全丢失 / 上游字符损坏 /
                 无引用浮动块归属 / 公式语义 / 无引用即无 ground truth）
设计取舍：5 类（undersized、referenceRatio、overlap 默认关、未触发路径、token 标定）
```

**下一步建议**：先做 **A（罗马前缀）** —— 唯一"无风险且通用"的剩余项；
**B / C / D** 需要你给出取舍边界后再设计；**E~K** 建议维持"只诊断不修"。
