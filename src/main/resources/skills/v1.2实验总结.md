# Skill: V1.2 Region-aware ECG SSL 实验总结

## 1. 版本定位

V1.2 系列是在 V1.1 基础上引入 MI 相关导联区域先验的 ECG 自监督预训练实验。

V1.1 已包含：

```text
MAE + MoCo + Strong Auxiliary Supervision

其中 Strong Auxiliary Supervision 使用稳定 ECG 自动测量特征：

HR / PR / QRS / QTc

V1.2 系列进一步引入：

INF / ANT / LAT 三个区域 token

用于显式建模心肌梗死相关导联区域信息。

2. 研究动机

MI 的 ECG 表现通常具有明显导联区域性。

例如：

区域	对应导联
inferior 下壁	II / III / aVF
anterior 前壁	V1 / V2 / V3 / V4
lateral 侧壁	I / aVL / V5 / V6

V1.1 主要依赖 global CLS 表征整条 ECG，可能会抹平 MI 相关的区域导联差异。

因此 V1.2 的核心思想是：

在自监督预训练中显式引入 MI 相关导联区域先验，
让模型不仅学习全局 ECG 表征，也学习下壁、前壁、侧壁区域表征。
3. V1.2 模型结构
3.1 Token 结构

V1.1 token 序列：

[CLS, P1, P2, ..., P50]

V1.2 token 序列：

[CLS, INF, ANT, LAT, P1, P2, ..., P50]

其中：

Token	含义
CLS	全局 ECG 表征
INF	下壁区域 token
ANT	前壁区域 token
LAT	侧壁区域 token
P1–P50	时间 patch token

总共：

1 个 global CLS token
3 个 region tokens
50 个 patch tokens
共 54 个 token
4. 区域导联划分

默认 12 导联顺序：

I, II, III, aVR, aVL, aVF, V1, V2, V3, V4, V5, V6

区域划分：

LEAD_REGIONS = {
    "inferior": [1, 2, 5],        # II, III, aVF
    "anterior": [6, 7, 8, 9],     # V1, V2, V3, V4
    "lateral":  [0, 4, 10, 11],   # I, aVL, V5, V6
}
5. V1.2-A2：温和区域监督版本
5.1 核心设计

V1.2-A2 包含：

Region Tokens
Region Contrast
Global-to-Region Fusion

训练目标：

L = L_MAE
  + 0.25 L_MoCo
  + 0.05 L_Strong
  + region_w L_Region
  + fusion_w L_Fusion

其中：

region_w 最大值 = 0.02
fusion_w 最大值 = 0.005
5.2 Region Contrast

V1.2-A2 中使用较温和的区域对比方式：

region_mode = random_one

即每个 batch 随机选择一个区域进行对比：

INF token ↔ inferior view
或 ANT token ↔ anterior view
或 LAT token ↔ lateral view

作用：

让 region token 学习对应导联区域信息，
但避免区域监督过强干扰主任务。
5.3 Global-to-Region Fusion

V1.2-A2 中 fusion 方式为：

global CLS → predict detached region_mean

其中：

region_mean = mean(INF, ANT, LAT)

公式：

z_region_mean = (z_inf + z_ant + z_lat) / 3.0
z_region_mean = z_region_mean.detach()

pred_region = global_to_region_head(z_global)

loss_fusion = 1 - cosine(pred_region, z_region_mean)

含义：

region tokens 作为 teacher，
global CLS 作为 student，
让 global CLS 温和吸收区域导联信息。
6. V1.2-A2 实验结果

V1.2-A2 最优结果：

指标	V1.1	V1.2-A2 最优	提升
5-class Linear AUC	0.8286	0.8459	+0.0173
MI Linear AUC	0.8117	0.8308	+0.0191
MI MLP AUC	0.8167	0.8396	+0.0229
MI MLP AUPRC	0.6337	0.6697	+0.0360

结论：

V1.2-A2 明显优于 V1.1。
说明区域导联先验能够增强 ECG 表征，
尤其对 MI binary 表征有帮助。
7. V1.2-A3：强区域监督版本
7.1 核心设计

V1.2-A3 在 A2 基础上进一步增强区域监督。

主要改动：

1. Region Contrast: random_one → all_regions
2. Fusion: region_mean fusion → region_wise fusion
7.2 All-region Contrast

A2：

每个 batch 随机训练一个区域

A3：

每个 batch 同时训练三个区域

即：

INF token ↔ inferior view
ANT token ↔ anterior view
LAT token ↔ lateral view

Region loss：

L_Region = (L_INF + L_ANT + L_LAT) / 3
7.3 Region-wise Fusion

A2 fusion：

global CLS → predict mean(INF, ANT, LAT)

A3 fusion：

global CLS → predict [INF, ANT, LAT]

即让 global CLS 分别预测三个区域 token：

target_regions = stack([z_inf, z_ant, z_lat]).detach()

pred_regions = global_to_regions_head(z_global)
pred_regions = pred_regions.view(B, 3, D)

loss_fusion = 1 - cosine(pred_regions, target_regions).mean()

设计目的：

让 global CLS 更细粒度地吸收 inferior / anterior / lateral 区域信息。
8. V1.2-A3 实验结果

A3 Linear 最优：

8.2 MLP Probe

A3 MLP 最优：

MI MLP AUC = 0.8282

MLP 结果整体低于 A2。

9. A2 与 A3 对比
指标	V1.2-A2 最优	V1.2-A3 最优	变化
5-class Linear AUC	0.8459	0.8429	-0.0030
MI Linear AUC	0.8308	0.8213	-0.0095
MI MLP AUC	0.8396	0.8282	-0.0114
MI MLP AUPRC	0.6697	0.6533	-0.0164

结论：

A3 没有进一步提升，反而在 MI 相关指标上下降明显。

说明：

区域导联辅助监督有效，但不能过强。
10. 阶段性结论
10.1 区域导联监督是有效的

V1.2-A2 相比 V1.1 明显提升：

MI Linear AUC: 0.8117 → 0.8308
MI MLP AUC: 0.8167 → 0.8396

说明：

引入 MI 相关导联区域先验，有助于模型学习更强的 MI 表征。
10.2 过强区域监督会产生负迁移

V1.2-A3 相比 A2 下降：

MI Linear AUC: 0.8308 → 0.8213
MI MLP AUC: 0.8396 → 0.8282

说明：

all-region contrast + region-wise fusion 约束过强，
可能使模型过度关注预定义导联区域一致性，
从而干扰 MAE / MoCo / Strong 主任务学习到的全局 ECG 表征。
10.3 最合理方向：轻量、温和、延后加入区域监督

当前结果支持：

区域导联信息应作为辅助监督，而不是主导优化目标。

后续训练策略应采用：

lower weight
delayed warmup
region_mean fusion
random_one or weak all-region contrast
11. 是否算创新点

可以算创新点，但建议表述为“方法改进点”或“小创新点”，不要夸大为全新框架。

推荐表述：

本研究将 MI 相关导联区域先验引入 ECG 自监督预训练，
通过新增 INF / ANT / LAT region tokens 与区域对比学习，
显式建模下壁、前壁和侧壁导联区域信息。

实验进一步表明，区域导联辅助监督能够提升 MI 表征，
但过强的区域约束会导致负迁移。
因此，区域先验应以轻量、温和的方式作为辅助监督加入，
而不是主导自监督优化目标。

更短版本：

创新点：提出 region-aware ECG SSL，在自监督预训练中引入 MI 相关导联区域先验；
并通过 A2/A3 对比验证区域辅助监督存在强度上限，
即适度区域监督有效，过强区域监督会干扰全局表征学习。
12. 后续训练策略

下一阶段不建议继续增强区域模块，而应优化训练策略。

推荐方向：

V1.2-A4: Conservative Region-aware Training

配置建议：

region_mode = "random_one"
fusion_type = "region_mean"

region_contrast_weight = 0.01
fusion_weight = 0.002

region_warmup_start = 10
region_warmup_end = 20

fusion_warmup_start = 15
fusion_warmup_end = 25

epochs = 50
mask_ratio = 0.6
moco_weight = 0.25
strong_weight = 0.05

设计逻辑：

1. 回退到更温和的 random_one region contrast；
2. 回退到 region_mean fusion；
3. 降低 region/fusion 权重；
4. 延后 warmup；
5. 让 MAE + MoCo + Strong 先稳定学习，再轻量加入区域监督。
13. 汇报用一句话
V1.2 系列实验表明，MI 相关导联区域先验能够提升 ECG 自监督表征，
但区域监督强度需要控制。
温和的 region-aware SSL 能提升 MI 表征，
而过强的 all-region contrast 与 region-wise fusion 反而会造成负迁移。
```
