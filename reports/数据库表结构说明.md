# 数据库表结构说明（PostgreSQL + pgvector）

> 数据库：PostgreSQL（镜像 `pgvector/pgvector:pg18`），端口 `15432`，库名 `ragdemo`
> 脚本：`sql/init.sql`（全新初始化，DROP+CREATE）· `sql/migration/V2__academic_chunk_columns.sql` · `sql/migration/V3__ingestion_mode_and_version.sql`
> 一致保证：`init.sql` 与两个 migration 已同步（新装 / 增量迁移结果一致）

---

## 一、总览

```text
knowledge_bases  (知识库)
    └── documents                (文档：上传/解析/入库状态)
            ├── document_chunks  (分块 + 向量 + 学术元数据 —— 检索主体)
            └── ingestion_tasks  (异步入库任务)

chat_conversations (会话：摘要 + 结构化状态)
    └── chat_messages (消息：短期记忆)
```

| # | 表 | 作用 | 行数量级 |
|---|---|---|---|
| 1 | `knowledge_bases` | 知识库；检索按 `knowledge_base_id` 隔离 | 个位数 |
| 2 | `documents` | 文档主表：文件元数据 + **解析模式/版本** + 状态机 + chunk 计数 | 每上传 1 行 |
| 3 | `document_chunks` | **检索主体**：chunk 文本 + `VECTOR(1024)` + 学术元数据（章节/类型/provenance） | 每篇数百行 |
| 4 | `ingestion_tasks` | 异步入库任务追踪（pending→running→success/failed + 进度） | 每上传 1 行 |
| 5 | `chat_conversations` | 会话：滚动摘要 `summary` + 结构化状态 `session_state` | 每会话 1 行 |
| 6 | `chat_messages` | 会话消息（滑窗记忆的来源） | 每轮 1~2 行 |

**外键级联**：`documents→knowledge_bases`（CASCADE）、`document_chunks→documents`/`knowledge_bases`（CASCADE）、`ingestion_tasks→documents`/`knowledge_bases`（CASCADE）、`chat_messages→chat_conversations`（CASCADE）

## 二、逐表字段说明

### 1. `knowledge_bases` — 知识库

| 字段 | 类型 | 约束 | 作用 |
|---|---|---|---|
| `id` | BIGSERIAL | PK | 知识库 ID；`init.sql` 预置 `id=1 默认知识库` |
| `name` | VARCHAR(255) | NOT NULL | 名称 |
| `description` | TEXT | | 描述 |
| `created_at` / `updated_at` | TIMESTAMP | NOT NULL DEFAULT NOW() | 时间戳 |

- 写入方：无代码入口（`init.sql` 预置）；`KnowledgeBasesMapper.existsById` 用于上传校验
- 检索隔离：`searchSimilarChunks` 用 `knowledge_base_id` 限定范围

### 2. `documents` — 文档主表

| 字段 | 类型 | 约束 | 作用 | 写入方 |
|---|---|---|---|---|
| `id` | BIGSERIAL | PK | 文档 ID（**persistence surrogate key**） | INSERT |
| `knowledge_base_id` | BIGINT | NOT NULL, FK→knowledge_bases | 所属知识库 | 上传 |
| `file_name` | VARCHAR(512) | NOT NULL | 用户上传时的原始文件名（也是传给解析器的文件名） | 上传 |
| `stored_file_name` | VARCHAR(512) | NOT NULL | 防重名的存储名（uuid+ext） | 上传 |
| `storage_path` | TEXT | NOT NULL | **MinIO object key**。ACADEMIC：`documents/{id}/versions/{v}/source/original{ext}`；GENERIC：`knowledge-base/{kbId}/{yyyyMMdd}/{uuid}{ext}` | 上传（先插空串，上传后 `updateStoragePath` 回填） |
| `file_size` | BIGINT | NOT NULL, CHECK ≥0 | 字节数 | 上传 |
| `content_type` | VARCHAR(255) | | MIME（参与 parseMode 自动判断） | 上传 |
| `file_ext` | VARCHAR(32) | | 扩展名（`.pdf/.docx/.txt/.md`） | 上传 |
| `checksum` | VARCHAR(128) | | **文件 SHA-256**；ACADEMIC 链路用它作为**领域 documentId**（内容寻址，避免用 DB id） | 上传 |
| `parse_mode` | VARCHAR(16) | NOT NULL DEFAULT 'AUTO', CHECK in (AUTO/ACADEMIC/GENERIC) | **三级决策的结果**（上传参数 > 配置默认 > 扩展名/MIME 自动）；异步 worker 据此分流 | 上传（V3 新增） |
| `version` | INT | NOT NULL DEFAULT 1, CHECK ≥1 | 解析版本号，用作 MinIO artifact key 的 `versions/{version}` 段 | 上传（V3 新增） |
| `status` | VARCHAR(32) | NOT NULL DEFAULT 'uploaded', CHECK in (uploaded/parsing/chunking/embedding/indexed/failed) | 状态机 | `IngestionStatusUpdater.updateDocumentStatus` |
| `progress` | INT | NOT NULL DEFAULT 0, CHECK 0~100 | 进度百分比 | 同上 |
| `chunk_count` | INT | NOT NULL DEFAULT 0, CHECK ≥0 | 已入库 chunk 数 | `updateChunkCount` |
| `error_message` | TEXT | | 失败原因（含 `ACADEMIC_*` 错误码前缀） | `updateDocumentStatus(..., "failed", 100, msg)` |
| `created_at` / `updated_at` | TIMESTAMP | NOT NULL DEFAULT NOW() | 时间戳 | — |

**状态机**（`DocumentStatus` 枚举与之对应）：
```text
uploaded → parsing → chunking → embedding → indexed
   └────────── 任一步失败 → failed（终态）
```

### 3. `document_chunks` — 分块 + 向量 + 学术元数据（**检索主体**）

| 字段 | 类型 | 约束 | 作用 | 写入方 |
|---|---|---|---|---|
| `id` | BIGSERIAL | PK | chunk 主键 | INSERT |
| `document_id` | BIGINT | NOT NULL, FK→documents | 所属文档（**DB id**，非领域 id） | 两条链路 |
| `knowledge_base_id` | BIGINT | NOT NULL, FK→knowledge_bases | 冗余知识库 ID（检索过滤用，免 JOIN） | 两条链路 |
| `chunk_index` | INT | NOT NULL, CHECK ≥0, **UNIQUE(document_id, chunk_index)** | 文档内序号（= 领域 `AcademicChunk.order`） | 两条链路 |
| `content` | TEXT | NOT NULL | **展示/引用用的纯净 chunk 文本**。ACADEMIC = `AcademicChunk.content`（无前缀）；GENERIC = splitter 片段 | 两条链路 |
| `page_number` | INT | | 起始页（ACADEMIC = `startPage`；GENERIC 暂为 null） | ACADEMIC |
| `token_count` | INT | | token 数（ACADEMIC = 估算器结果；GENERIC 暂为 null） | ACADEMIC |
| `start_offset` / `end_offset` | INT | | 字符偏移。**当前两条链路都不写（恒为 null）**，仅保留列以兼容旧设计 | — |
| `metadata` | JSONB | | **长尾元数据**。ACADEMIC 写入：`blockTypes`、`sourceBlockIds`、`overlapBlockIds`、`referenceIds`、`charCount`、`oversized`、`undersized`、`titleContext` | ACADEMIC |
| `embedding` | VECTOR(1024) | | **向量**。ACADEMIC 由 `AcademicChunk.embeddingText` 计算；GENERIC 由 `content` 计算 | 两条链路 |
| `chunk_key` | TEXT | UNIQUE(document_id, chunk_key) | 稳定 key = `AcademicChunk.chunkId`（`{领域docId}:{scopeId}:{index}`），供幂等/回溯 | ACADEMIC（V2 新增） |
| `chunk_type` | VARCHAR(16) | | 高层类型：`TEXT/LIST/FIGURE/TABLE/FORMULA/FOOTNOTE/CAPTION/MIXED/ABSTRACT/REFERENCE` | ACADEMIC（V2 新增） |
| `section_id` | VARCHAR(255) | | 所属 section id | ACADEMIC（V2 新增） |
| `section_title` | TEXT | | 所属 section 标题 | ACADEMIC（V2 新增） |
| `section_path` | TEXT[] | GIN 索引 | 章节路径，如 `{"4. Methods","4.1 Datasets"}`；section-aware 过滤/facet/rerank 用 | ACADEMIC（V2 新增） |
| `section_level` | INT | | 章节层级 | ACADEMIC（V2 新增） |
| `embedding_text` | TEXT | | **真正送 embedding 的文本**（= `Document:` 标题 + `Section:` 路径 + content）。与 `content` 分离保存，用于复现 embedding / debug / content-vs-embeddingText 消融 | ACADEMIC（V2 新增） |
| `content_hash` | VARCHAR(16) | | `embeddingText` 的 SHA-256 前 16 位（变更检测） | ACADEMIC（V2 新增） |
| `end_page` | INT | | 结束页（学术 chunk 可跨页） | ACADEMIC（V2 新增） |
| `created_at` | TIMESTAMP | NOT NULL DEFAULT NOW() | 时间戳 | — |

> **两条链路的关键差异**：GENERIC 只写 `document_id/kb_id/chunk_index/content/embedding`；
> ACADEMIC 额外写全部学术列，且 **`embedding` 来自 `embedding_text` 而不是 `content`**。

## 四、检索 SQL（`resources/mapper/DocumentChunkMapper.xml`）

```sql
SELECT dc.id AS chunkId, dc.document_id AS documentId, d.file_name AS documentName,
       dc.page_number AS page, dc.chunk_index AS chunkIndex, dc.content AS content,
       1 - (dc.embedding <=> CAST(#{questionEmbedding} AS vector)) AS score
FROM document_chunks dc
JOIN documents d ON dc.document_id = d.id
WHERE dc.knowledge_base_id = #{knowledgeBaseId}
  AND d.status = 'indexed'                 -- 未完成入库的文档不参与问答
ORDER BY dc.embedding <=> CAST(#{questionEmbedding} AS vector)
LIMIT #{topK}
```
- `<=>` = pgvector 余弦距离；`1 - 距离` = 余弦相似度（`ChatServiceImpl` 再按 `minScore`（默认 0.3）过滤）
- **目前只按 `knowledge_base_id` + `documents.status` 过滤**；`chunk_type` / `section_path` 等新列**尚未用于过滤**（为后续 section-aware 检索预留）
