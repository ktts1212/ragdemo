## 3. 过程中发现并修复的 3 个真实缺陷（都会阻塞应用启动）

| # | 缺陷 | 症状 | 修复 |
|---|---|---|---|
| 1 | `MarkerHttpClient` 有**两个构造器**（生产 1 参 + 测试 3 参包私有）却**无 `@Autowired`** | Spring 无法选择构造器 → 退化为要求无参构造 → `No default constructor found` | 给生产构造器加 `@Autowired` |
| 2 | `GrobidHttpClient` **同样问题** | 修完 #1 后必然倒在这 | 同上（提前一并修复） |
| 3 | `pom.xml` 把 `httpclient5` 钉在 **5.6.2**，与 Spring Boot 3.3.5 管理的 `httpcore5` **5.2.5** 不兼容 | `ManagedHttpClientConnectionFactory` / `DefaultHttpRequestWriterFactory` classpath 冲突 | 去掉显式 `<version>`，交由 Spring Boot BOM 管理（自动对齐） |

> 这 3 个都是**运行期才暴露**的问题，之前的 230 个单测（纯离线）与 `mvn compile` 都发现不了。
